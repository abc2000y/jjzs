# A股基金智能分析助手 V1.0

## 本包包含
- `index.html`：手机端网页界面
- `app.js`：腾讯实时行情、三年日K、指标计算与本机缓存
- `README.md`：部署与验收说明

## 部署到 GitHub Pages（不覆盖原主页）
1. 解压 ZIP。
2. 在仓库 `abc2000y.github.io` 中新建文件夹 `fund-assistant-v1`。
3. 将本项目的 `index.html`、`app.js`、`README.md` 上传到该文件夹。
4. 提交后访问：`https://abc2000y.github.io/fund-assistant-v1/`
5. 原根目录 `index.html` 不需要修改，因此不会破坏现有主页。

## 数据与计算
- 实时行情：腾讯 `qt.gtimg.cn`，通过脚本变量读取。
- 历史行情：腾讯 `web.ifzq.gtimg.cn/appstock/app/fqkline/get`，按年度分段取日K。
- 历史优先使用 `qfqday`（前复权）；若无则回退 `day`。
- 计算：近1年/近3年收益、区间最大回撤、年化波动率、MA20/60/120、RSI14、MACD。
- 浏览器本机缓存：6小时。清除浏览器站点数据会清除缓存。

## 重要说明
1. 这是第一阶段可部署测试版，不代表腾讯接口在所有网络/浏览器环境都保证可用。腾讯公开接口不是正式稳定的商业API，可能变更或限流。
2. 若历史接口请求失败，页面会显示错误，不会填充模拟数据或用0代替缺失数据。
3. 由于本次交付环境无法替用户的 GitHub Pages 域名进行线上验收，必须由你部署后实际点击“查询并分析”验收。若仍出现历史0条，请把页面“状态”区域完整文字和浏览器控制台错误发回，以便针对腾讯实际响应修复。
4. 收益率基于历史K线收盘价计算，且使用前复权数据时会受复权因子影响；不能与基金净值收益完全等同。
5. 当前仅有三只ETF下拉选项；尚未接入全市场基金档案、基金经理、规模、费率、持仓、公告、组合管理，也不应将这些未实现功能宣传为已完成。
6. GitHub Pages 适合个人或小规模测试。若面向微信公众号大量用户，应增加自有服务器代理、缓存、限流与监控。

## 故障排查
- 若页面显示“脚本加载失败”：检查网络能否访问腾讯行情域名，或接口是否调整。
- 若实时行情失败但历史成功：先保留历史分析结果，并记录实时行情错误。
- 若历史数据为0条或格式不符：记录状态文字；腾讯接口可能返回了不同的包装格式，需要按实际响应调整解析。
- 该项目无需安装 Python、Node 或数据库，纯静态网页即可运行。
