数据说明与限制

  • 本版本是可部署的第一阶段测试版，不等同于已完成全品类基金数据库。
  • 腾讯接口为公开网页接口，可能调整、限流或受网络环境影响；失败时会明确提示，不以模拟数据替代。
  • 历史K线使用前复权日K（qfqday优先，接口不提供时回退day），收益计算基于所取价格序列；前复权价格可能随分红等因素调整。
  • 最大回撤、波动率和技术指标均基于本次实际取得的历史收盘价，不构成投资建议。
  • GitHub Pages 适合个人/小规模测试。面向公众号大量用户长期使用，建议增加自有服务器代理、缓存和访问频率控制。
